# leave_managemet_system
ระบบจัดการลางานออนไลน์
LeaveFlow Pro เป็นเว็บแอปพลิเคชันสำหรับบริหารจัดการและยื่นคำขอลางานภายในองค์กร พัฒนาขึ้นด้วย HTML, CSS (Bootstrap 5) และ JavaScript รองรับระบบการทำงานทั้งฝั่งพนักงานทั่วไปและฝั่งผู้บริหาร (Admin) พร้อมระบบคำนวณวันลาอัตโนมัติที่หักวันหยุดนักขัตฤกษ์และวันหยุดเสาร์-อาทิตย์ให้เสร็จสรรพ

🚀 1. ฟีเจอร์หลักของระบบ (Key Features)
ฝั่งพนักงาน (Employee Dashboard)
ระบบเข้าสู่ระบบยืดหยุ่น: สามารถเลือกชื่อพนักงานจากรายชื่อในระบบ หรือพิมพ์ชื่อ-นามสกุลเพื่อเข้าใช้งานแบบกำหนดเองได้ทันที

แดชบอร์ดแสดงโควตาคงเหลือ: แสดงจำนวนวันลาคงเหลือแยกตามประเภท (ลาป่วย, ลากิจ, ลาพักผ่อน) แบบเรียลไทม์

ยื่นคำขอลาออนไลน์: กรอกแบบฟอร์มเลือกประเภทการลา ระบุช่วงวันที่เริ่มต้น-สิ้นสุด และใส่เหตุผลความจำเป็น

ตรวจสอบประวัติการลา: ตารางแสดงประวัติและสถานะคำขอลาของตนเอง (รออนุมัติ, อนุมัติ, ไม่อนุมัติ) พร้อมระบุชื่อผู้อนุมัติ

ฝั่งผู้บริหาร / แอดมิน (Admin Dashboard)
ระบบความปลอดภัยด้วย PIN: เข้าสู่ระบบผู้บริหารพร้อมเลือกรายชื่อแอดมินผู้ดำเนินการ (เช่น คุณพิชญ์สินี ทับพยุง หรือ คุณณัฐพงศ์ พรมสงฆ์) และใส่รหัส PIN เพื่อยืนยันตัวตน

อนุมัติ / ปฏิเสธคำขอลา: ตรวจสอบรายการคำขอลาที่รออนุมัติ พร้อมปุ่มกดอนุมัติหรือปฏิเสธคำขอได้ทันที

ระบบหักโควตาอัตโนมัติ: เมื่อผู้บริหารกดอนุมัติ ระบบจะทำการหักวันลาออกจากโควตาของพนักงานคนนั้น ๆ ทันที

ประวัติการลาย้อนหลังทั้งหมด (Admin Log): บันทึกและแสดงประวัติการทำรายการทั้งหมดในระบบ พร้อมระบุชื่อผู้บริหารที่

สรุปสถานะวันลาพนักงานทั้งหมด: ตารางสรุปข้อมูลรหัส ชื่อ ตำแหน่ง แผนก และวันลาคงเหลือของพนักงานทุกคนในองค์กร

ระบบรีเซ็ตข้อมูล: ปุ่มสำหรับล้างข้อมูลและคืนค่าระบบกลับสู่ค่าเริ่มต้น (Reset System)

📊 2. ประเภทวันลาและโควตาเริ่มต้น (Leave Types & Quotas)
ระบบมีการกำหนดโควตาวันลาเริ่มต้นต่อปีให้กับพนักงานแต่ละคน ดังนี้:

🩺 ลาป่วย: 30 วัน/ปี

ธุระ ลากิจ: 6 วัน/ปี

🏖️ ลาพักผ่อน (พักร้อน): 10 วัน/ปี

🧠 3. ระบบคำนวณวันลาอัจฉริยะ (Smart Leave Calculation)
ระบบจะทำการตรวจสอบช่วงวันที่พนักงานเลือกยื่นลา

หักวันหยุดอัตโนมัติ: ระบบจะคํานวณเฉพาะวันทำงานจริง โดยทำการตัดวันหยุดเสาร์-อาทิตย์ และวันหยุดนักขัตฤกษ์ประจำปี 2026 ออกจากการนับจำนวนวันลาโดยอัตโนมัติ เพื่อความยุติธรรมและแม่นยำ

🔐 4. สิทธิ์การใช้งานและระบบความปลอดภัย (Roles & Security)
Employee Mode: สำหรับพนักงานทั่วไป ใช้ยื่นใบลาและดูประวัติของตนเอง

Admin Mode: สำหรับผู้บริหาร ป้องกันด้วยรหัส PIN (1234) และระบุตัวตนผู้บริหารที่กำลังปฏิบัติงาน

🛠️ 5. เทคโนโลยีที่ใช้ในการพัฒนา (Tech Stack)
Frontend: HTML5, CSS3

Framework: Bootstrap 5 (UI Design Responsive)

Icons: Font Awesome 6

Fonts: Google Fonts (Plus Jakarta Sans)

State Management & Storage: JavaScript (Vanilla JS) ร่วมกับ localStorage สำหรับจำลองฐานข้อมูลฝั่งClient-side

⚙️ 6. วิธีเริ่มใช้งานโปรเจกต์ (Getting Started)
Clone หรือดาวน์โหลดไฟล์โปรเจกต์ทั้งหมดมาไว้ในเครื่องคอมพิวเตอร์ของคุณ

เปิดไฟล์ index.html ผ่านเว็บ浏览器 (Chrome, Edge, Safari ฯลฯ) ได้ทันทีโดยไม่ต้องติดตั้ง Server เพิ่มเติม

ทดเข้าสู่ระบบ:

พนักงาน: เลือกชื่อพนักงานจากลิสต์ แล้วคลิก "เข้าสู่ระบบพนักงาน"

ผู้บริหาร: คลิกปุ่ม "เข้าสู่ระบบผู้บริหาร (Admin)", เลือกชื่อผู้บริหาร และกรอกรหัส PIN (1234)
