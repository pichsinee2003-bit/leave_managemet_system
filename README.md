# 🏢 ระบบบริหารจัดการการลางาน (Leave Management System)

ระบบบริหารจัดการการลางานอัจฉริยะที่พัฒนาขึ้นด้วย **Python (Flask)** ร่วมกับ **Bootstrap 5** รองรับการใช้งานแบบ Multi-Company (หลายบริษัท) และระบบผู้อนุมัติหลายระดับ (Multiple Approvers) พร้อมฟังก์ชันคำนวณวันลาอัตโนมัติ หักวันหยุดนักขัตฤกษ์/วันอาทิตย์ และระบบตรวจสิทธิ์แบบเรียลไทม์

---

## 🚀 ฟีเจอร์หลักของระบบ (Key Features)

### 1. 👥 ระบบสมาชิกและการเข้าสู่ระบบ (Authentication)
* **โหมดพนักงาน (Employee View):** 
  * เข้าสู่ระบบด้วยรหัสพนักงานตามบริษัทที่สังกัด
  * ตรวจสอบโควตาวันลาคงเหลือแบบ Real-time (ลาพักร้อน, ลาป่วย, ลากิจ)
  * ยื่นคำขอลางาน (รองรับทั้งแบบเต็มวันและครึ่งวัน พร้อมระบุช่วงเวลา)
  * **ระบบมอบหมายงานแทน (Task Handover):** เลือกเพื่อนร่วมงานเพื่อปฏิบัติงานแทนพร้อมแนบโน้ต/ลิงก์งาน
  * แนบไฟล์เอกสารประกอบการลา (รูปภาพ หรือ PDF) พร้อมระบบพรีวิวไฟล์แนบ
  * ตรวจสอบประวัติสถานะการลา และขอยกเลิก/ขอคืนวันลาได้
* **โหมดผู้อนุมัติ / HR (Approver View):**
  * รองรับผู้อนุมัติหลายคนต่อบริษัท (Main Approver / Backup Approver)
  * ระบบแจ้งเตือน (Notification Banner) แจ้งเตือนเมื่อมีคำขอลาหรือคำขอคืนวันลาใหม่
  * อนุมัติ (Approve) หรือ ปฏิเสธ (Reject พร้อมระบุเหตุผล) คำขอลา
  * อนุมัติการคืนวันลา (Cancel/Refund Quota)
  * **จัดการข้อมูลองค์กร:** เพิ่มบริษัทใหม่, เพิ่มผู้อนุมัติใหม่, เพิ่ม/ลบพนักงาน และเปลี่ยนรหัสผ่านพนักงาน
  * **จัดการประเภทการลา (Leave Type Configuration):** เพิ่ม/แก้ไขประเภทการลาและโควตาตั้งต้นได้อิสระ

### 2. 📅 ปฏิทินวันลาและวันหยุด (Team Calendar & Holidays)
* ปฏิทินทีมแบบรายเดือน แสดงสถานะการลาของเพื่อนร่วมงานและวันหยุดนักขัตฤกษ์
* **ระบบจัดการวันหยุดนักขัตฤกษ์ (Dynamic Holidays):** กำหนดวันหยุดประจำปีของแต่ละบริษัทได้

### 3. 🧠 ระบบแจ้งเตือนอัจฉริยะ (Smart Capacity & Validation)
* **Smart Capacity Warning:** ระบบแจ้งเตือนอัตโนมัติหากมีพนักงานในแผนกเดียวกันลาในช่วงเวลาเดียวกันเกิน 50% เพื่อป้องกันปัญหาขาดแคลนกำลังพล
* **Overlap Validation:** ป้องกันการยื่นใบลาซ้ำซ้อนในช่วงวันที่เคยลาไปแล้ว
* **Email Simulation Modal:** จำลองการส่งอีเมลแจ้งผลการพิจารณาใบลาไปยังพนักงานอัตโนมัติ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)
* **Backend:** Python, Flask
* **Frontend:** HTML5, Bootstrap 5 (CSS & JS), Bootstrap Icons, Google Fonts (Sarabun)
* **Storage:** LocalStorage (ฝั่ง Client-side สำหรับจำลองฐานข้อมูลในการทดสอบระบบ)

## ⚙️ วิธีการติดตั้งและรันโปรเจกต์ (Installation & Running)

### 1. ติดตั้ง Python และ Flask
ตรวจสอบว่าในเครื่องของคุณติดตั้ง Python ไว้เรียบร้อยแล้ว จากนั้นติดตั้ง Flask ผ่านเทอร์มินัล (Terminal / Command Prompt):
```bash
pip install Flask
```

### 2. สร้างไฟล์โปรเจกต์
สร้างไฟล์ Python ขึ้นมา 1 ไฟล์ (เช่น `app.py`) แล้วนำโค้ดระบบทั้งหมดของคุณวางลงไปในไฟล์ดังกล่าว

### 3. รันโปรเจกต์
รันคำสั่งด้านล่างนี้ผ่าน Terminal:
```bash
python app.py
```

### 4. ใช้งานผ่านเว็บเบราว์เซอร์
เปิดเบราว์เซอร์แล้วเข้าสู่ลิงก์: http://127.0.0.1:5000

## 🔑 ข้อมูลทดสอบระบบเริ่มต้น (Default Login Credentials)

ระบบมีข้อมูลตัวอย่างสำหรับทดสอบทันทีโดยใช้ **รหัสผ่านเริ่มต้นคือ `1234`** สำหรับทุกบัญชี:

* **พนักงานตัวอย่าง:** 
  * บริษัท: *บริษัท เทคโนโลยี นวัตกรรม จำกัด*
  * พนักงาน: **นายสมชาย สายชิว** (`EMP001`) | แผนก: ฝ่ายพัฒนาระบบ
* **ผู้อนุมัติ / HR ตัวอย่าง:**
  * บริษัท: *บริษัท เทคโนโลยี นวัตกรรม จำกัด*
  * ผู้อนุมัติ: **ดร.วิกรม นวัตกรรม** (`APPR001_1`) | ผู้จัดการทั่วไป
