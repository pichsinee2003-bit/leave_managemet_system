## 📖 เกี่ยวกับโปรเจกต์ (About)
**Enterprise Leave Management System** ถูกพัฒนาขึ้นเพื่อช่วยลดความซับซ้อนและเพิ่มประสิทธิภาพในการบริหารจัดการคำขอลาของพนักงานภายในองค์กร รองรับการใช้งานผ่านเว็บเบราว์เซอร์ ช่วยให้ทั้งพนักงานและฝ่ายบริหารสามารถตรวจสอบสถานะ ประวัติการลา และจัดการข้อมูลได้อย่างสะดวกรวดเร็ว

---

## ✨ ฟีเจอร์หลักของระบบ (Key Features)

* **📝 ระบบยื่นคำขอลา:** พนักงานสามารถกรอกข้อมูลและส่งคำขอลาประเภทต่างๆ ผ่านระบบออนไลน์ได้อย่างง่ายดาย
* **🏢 ระบบจัดการข้อมูลองค์กร:** รองรับการเพิ่ม แก้ไข และบริหารจัดการข้อมูลพนักงานและฟังก์ชันภายในบริษัท
* **📊 หน้าจอแสดงผลแบบ Real-time:** เชื่อมต่อและทำงานผ่าน Local Server พร้อมแสดงผลหน้าเว็บผ่านเบราว์เซอร์ทันที
